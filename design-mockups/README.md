# Monomovie — UI/UX redesign mockup

A standalone React + Vite mockup for redesigning [Monomovie](../Readme.md)
("bookmark, select and watch movies"), built **outside the app codebase** on
purpose: nothing here is wired to the Ktor backend, and the real code was not
touched. Real content (posters, offers, ratings, provider icons) is harvested
from the app's own `cached_movies.json`, so the mockups show what the app
actually deals with.

## Run it

```sh
pnpm install
pnpm dev          # http://localhost:5173
```

Screenshots of every view: `shots/`.

## The redesign in one sentence

The app is not a catalog — it is a decision instrument ("what do we watch
tonight?"), so every screen is rebuilt around the **shortlist → pick → spin →
watch → log** loop, with the picked-for-tonight state made a persistent,
visible object instead of a disabled grey button.

## What changed per surface

| Surface          | Current app                                   | Mockup                                                                 |
| ---------------- | --------------------------------------------- | ---------------------------------------------------------------------- |
| Home             | "Bookmarked Movies:", tall list rows          | **Shortlist**: poster grid, hover detail, filter chips                 |
| Decision         | Weights only inside `/roulette`               | **Decision bar** fixed at bottom; picked movies carry wheel colours     |
| Roulette         | Redirect to external wheel (providence)       | In-app wheel (donut, weights, spin → winner card). Shared room + QR     |
| Offers page      | All ISO countries tabled at once              | DE-first groups (subscription / free / rent / buy), countries collapsed |
| Watched          | Date-grouped list                             | Month-grouped ledger with one-line rows and un-watch affordance        |
| Search           | Separate page + infinite scroll               | Ambient header search (`/` shortcut), live results, type badge         |
| Ratings          | 4-icon cluster, no hierarchy                  | One quiet verdict row (IMDb chip + tomato % fallback TMDB)             |

Design tokens: ink-violet chrome `#15131B` / `#1D1A26`, warm ivory `#EFEBE4`,
brand amber `#F69E45` (from the existing bookmark ribbon) as the *only*
semantic accent; posters and provider logos carry all other colour.
Type: **Bricolage Grotesque** (display) + **IBM Plex Sans** (UI).

## Feature suggestions included in the mockup

1. In-app wheel (external dependency stays optional), weights shown as odds
2. Type badges — JustWatch search results leak TV series today
3. DE-first country groups instead of the full country dump
4. Filter chips on the shortlist ("Streaming in DE", "Hide watched")
5. Space for a compact "added on" date to support cache-age transparency

## Files of interest

- `src/data.ts` — curated real data (generated by `scripts/gen-data.cjs`)
- `src/styles.css` — the whole design system
- `src/ShortlistView.tsx`, `MovieDetail.tsx`, `RouletteView.tsx`, `WatchedView.tsx` — the four surfaces
- `scripts/shoot.mjs` — Playwright screenshot generator (needs `PLAYWRIGHT_BROWSERS_PATH=/tmp/opencode/pw-browsers`)
